CELER / PRIVACIDAD

Política de privacidad

Extensión CELER — Gestor de rendimiento para Chrome, versión 0.1.0.

Última actualización: 14 de octubre de 2026.

Resumen: CELER administra pestañas y procesa determinada información de navegación de manera local para suspender, recargar o cerrar pestañas, proteger formularios y aplicar optimizaciones opcionales. No utiliza cuentas, servidores propios, anuncios ni herramientas de seguimiento remoto. Sus datos no se venden ni se envían al desarrollador.

1. Finalidad

CELER tiene como único propósito gestionar el rendimiento y los recursos del navegador mediante suspensión, recarga, cierre y recuperación de pestañas, así como protecciones y ajustes de recursos directamente relacionados con esa finalidad.

2. Información que procesa

  • Pestañas y navegación: dirección URL, nombre o título de pestañas abiertas, dominio, estado activo o suspendido, indicadores de audio, fijación e instante de último acceso. Se utilizan para decidir qué pestañas gestionar y cuáles proteger.
  • Recuperación de pestañas: al usar la función de cierre y recuperación, CELER guarda temporalmente la URL; con Auto KillTab opcional también guarda localmente el título y la fecha de cierre. El archivo automático conserva hasta 50 entradas.
  • Preferencias y estadísticas: ajustes, dominios protegidos, reglas de recarga y contadores de acciones; se conservan localmente en el perfil de Chrome.
  • Actividad y formularios: detecta únicamente si hubo una modificación en un campo editable (indicador verdadero/falso); no lee ni almacena los valores escritos. Opcionalmente usa eventos de desplazamiento y movimiento del puntero sobre enlaces para guardar la posición vertical de desplazamiento de una página o precargar enlaces del mismo sitio. No construye perfiles de comportamiento.
  • Elementos de páginas: reconoce localmente estructuras y elementos, como campos editables, imágenes, reproductores, avisos de cookies y enlaces, exclusivamente para las funciones opcionales de protección y optimización. No extrae ni conserva el texto de las páginas, correos o conversaciones.
  • Memoria del equipo: consulta capacidad y memoria física disponible para ajustar la suspensión. No la envía fuera del navegador.

Advertencia: algunas URL pueden incluir parámetros con información personal o identificadores de sesión introducidos por los sitios visitados. El archivo de recuperación conserva la URL completa y puede contener esos parámetros; utiliza la función de limpieza del archivo cuando lo necesites.

3. Dónde se almacenan los datos

Los ajustes, estadísticas y archivo de recuperación automática se guardan en chrome.storage.local dentro del perfil local de Chrome. El estado de formularios y el último cierre manual se gestionan en chrome.storage.session. Si está habilitada la restauración de desplazamiento, la posición se guarda en sessionStorage de la página correspondiente. La extensión no utiliza sincronización remota ni una base de datos propia.

4. Transferencias y terceros

CELER no transmite a servidores del desarrollador URL, títulos, contenido de páginas, datos de formularios, estadísticas ni información del equipo. No vende, comercializa ni comparte estos datos con anunciantes ni intermediarios. Algunas funciones activadas por el usuario, como la precarga de enlaces o el rechazo de cookies, pueden provocar solicitudes normales del navegador al sitio web abierto; esas solicitudes no constituyen una transferencia a un servidor de CELER.

5. Conservación y eliminación

Las preferencias y estadísticas permanecen hasta que el usuario borre los datos de la extensión o la desinstale. El archivo de hasta 50 URL se actualiza cuando Auto KillTab guarda nuevas entradas y puede vaciarse desde CELER. Los estados temporales de sesión no están diseñados como historial permanente. Desinstalar la extensión elimina normalmente sus datos almacenados en el perfil local de Chrome. CELER no dispone de una copia en sus propios servidores para recuperar datos eliminados.

6. Permisos del navegador

CELER utiliza los permisos tabs (administrar pestañas), storage (guardar ajustes y archivo local), alarms (programar revisiones), system.memory (conocer RAM física), declarativeNetRequest (reglas locales opcionales para recursos) y acceso a páginas HTTP/HTTPS (detectar cambios en formularios y aplicar optimizaciones de elementos). Las reglas opcionales pueden modificar la carga o presentación de algunos sitios web.

7. Seguridad y alcance

El código de CELER 0.1.0 se incluye en la extensión y no descarga código JavaScript ejecutable remotamente. La extensión no garantiza restaurar estados de páginas, sesiones, formularios o datos no guardados tras un cierre o una recarga. El acceso al perfil de Chrome y los datos locales depende también de la seguridad del dispositivo.

8. Usos limitados de datos

CELER utiliza los datos solo para proporcionar o mantener las funciones descritas. No los utiliza para publicidad personalizada, calificación crediticia, intermediación de datos ni fines distintos. El uso de la información recibida de las API de Chrome cumple con la Política de datos de usuario de Chrome Web Store, incluidos sus requisitos de uso limitado.

9. Actualizaciones y contacto

Si futuras versiones incorporan funciones que cambien la forma en que CELER utiliza datos, se actualizará esta página y las declaraciones de privacidad en Chrome Web Store antes de publicarse. Para consultas relacionadas con privacidad, utiliza el correo de contacto del editor indicado en la ficha oficial de CELER en Chrome Web Store.

CELER — Extensión independiente. Este documento describe exclusivamente la versión 0.1.0 y no sustituye los avisos de los sitios que visitas.
